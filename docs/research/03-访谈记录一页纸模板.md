# 03 · 访谈记录一页纸模板

> 每场访谈一页,24h 内完成;`P{编号}-{日期}` 命名,存 `docs/research/interviews/`(录音与原话
> 引用先脱敏再入库)。汇总口径见 05 文档 §3:痛点标签、原话引用、付费信号 0–2。

```markdown
# P01 · 2026-09-XX · 线上 · 来源:MPU Talk · 主持:D1

## 画像
工具史:Things 3(2 年)→ 放弃 → 现 Apple 提醒事项 + 纸笔
GTD 深度:收件箱 ✓ / 周回顾 ✗(试过 3 次放弃) / next action 半个 / 项目 ✗
任务量:每周 ~40 条新增;管理耗时 ~3h/周

## 痛点(标签 + 强度 1–3)
- [收件箱积压] 3 —— "微信里答应的事两天就忘"
- [回顾缺失] 2
- [拆解困难] 1

## 原话引用(逐字,可进评估集/营销叙事的标 ⭐)
- "我不是不想整理,是每次打开清单就被 200 条过期任务劝退" ⭐
- (任务表述原文,补入评估集):"下礼拜三之前把体检报告取了 半小时"

## AI 反应
- 澄清副驾:信任点=不用自己想分类;恐惧点=它乱归项目我还得返工
- 拆解师:"我要是能描述清楚,我自己就拆了" ← 关键怀疑
- 规划师:最想要,但"被打断就废了"
- 隐私底线:任务内容可以上云,但"别拿去训练"

## 付费信号:2
- Van Westendorp:便宜到可疑 ¥10/月;划算 ¥30/月($4-5);贵但考虑 ¥60;不买 >¥100
- 买断偏好:愿意 $70 一次性

## 待办
- [ ] 转介绍:P02(他的合伙人,同样 Things 流失)
- [ ] 原话入评估集:1 条已脱敏提交 PR
```

## 痛点标签词表(汇总时统一)

`收件箱积压` `回顾缺失` `拆解困难` `工具切换流失` `提醒焦虑` `过度整理`

## 汇总规则(G0 证据包)

- 付费意愿:信号为 2 的人数占比 ≥60% 即 G0 达标(05 文档 §5 检查项 4)。
- 痛点验证:与报告 §7 六大痛点逐一对上"验证/证伪/未触及"。
- 评估集贡献:每场至少尝试收集 2–3 条真实任务表述(脱敏后)。
