# 01 · 访谈筛选问卷（v1）

> 目标：从 ≥40 名报名者中筛出 20 场访谈。配额硬约束：**OmniFocus/Things 流失或重度用户 ≥10**；
> GTD 实践者（做过每周回顾）≥12；付费能力无硬门槛但收入敏感度留档。
> 形式：Tally 表单，5 分钟内可完成；Q1–Q4 为资格题。

## A. 资格筛选（Q1–Q4）

**Q1. 你目前主要用什么工具管理任务？（多选）**
- OmniFocus / Things 3 / Todoist / Notion / Apple 提醒事项 / 纸笔或手账
- 飞书/钉钉任务 /滴答清单 / 其他（自填）/ 基本不用工具

**Q2. 过去 12 个月里，你是否从某个任务管理工具换到过另一个，或放弃过某个工具？**
- 是（追问工具名与原因，open text）
- 否

**Q3. 你听说过 GTD（Getting Things Done）吗？做到过以下哪些？（多选）**
- 没听过 / 听过但没实践
- 有一个统一收件箱的习惯
- 做过每周回顾（weekly review）
- 用"下一步行动"（next action）拆解任务
- 用项目清单管理多步任务

**Q4. 你每周大概花多少时间处理"任务管理"这件事本身（整理清单、回顾、打标签等）？**
- <30 分钟 / 30–120 分钟 / 2–5 小时 / >5 小时

## B. 画像补充（Q5–Q8，不淘汰）

**Q5. 你的主要工作形态**：知识工作者 / 学生 / 自由职业 / 管理者 / 其他
**Q6. 平台**：Mac + iPhone / 仅 iPhone / 仅 Mac / Android / 混合多平台
**Q7. 每周新增任务量（估）**：<10 / 10–30 / 30–100 / >100
**Q8. 你对 AI 帮你整理任务的态度**：很感兴趣 / 谨慎乐观 / 只要不碰我数据无所谓 / 不想用

## C. 排期与激励（Q9–Q10）

**Q9. 未来两周可接受访谈时段**（工作日晚 / 周末上午 / 周末下午，多选；线上/线下）
**Q10. 联系方式 + 是否愿意加入候补名单**（邮箱/微信，选填）

## 评分与分层规则

| 信号 | 分值 |
| --- | --- |
| OmniFocus 或 Things 现役/流失用户（Q1/Q2） | +3（满足配额优先排期） |
| 从付费工具流失（Q2 有原因描述） | +2 |
| 做过每周回顾（Q3） | +2 |
| 每周任务管理投入 ≥2h 或新增 ≥30 条（Q4/Q7） | +1 |
| 对 AI 态度正面（Q5=很感兴趣/谨慎乐观） | +1 |
| 基本不用工具 / 纯学生无 GTD 接触 | -2（不计入本轮，转入候补名单） |

- 总分 ≥5：优先排期（按报名顺序取 20）；3–4：候补（有放鸽子时递补）。
- **多样性检查**：排期名单中，"已放弃 GTD"者 ≥3、"Apple 提醒事项党" ≥2，
  避免全量 GTD 老手导致痛点样本偏倚。
- 报名不足 40 时：追加渠道投放（见 04 文档渠道清单），不降低配额标准。
