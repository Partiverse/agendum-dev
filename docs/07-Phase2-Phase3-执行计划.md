| 工作流 | 交付 |
| --- | --- |
| AI/后端 | **MCP Server v1**（官方 Dart SDK，ADR-010）：工具集直接复用 04 文档 §3 定义（search_tasks / create_task / update_task / reschedule / summarize_period）；本地 stdio + 远程托管两种接入；授权模型 = 最小范围授权（只读/读写分档）+ 审计日志 + 撤销 |
| 后端 | 公开 API v1：REST + WebSocket 订阅（oplog 增量流）；API key 管理、限流、配额（免费/Pro 分级） |
| 安全 | 第三方代理接入的威胁模型评审（token 轮换、异常调用检测）——任务库是用户最私密数据，代理生态是最大新增攻击面 |

### M14（S27–S28）：生态验证 + 捕获补全

- MCP/API 打磨与**第三方集成案例 ≥10 个**：与效率社区开发者共创（快捷指令示例、Obsidian 插件样例、Claude/ChatGPT 代理配置模板），案例入库公开页。
- 邮件转发捕获：每用户专属转发地址 → 解析入收件箱（复用捕获解析链）。
- 分享面板全平台（iOS/macOS/Android/Windows）。

### M15（S29–S30）：今日规划师 v2 + 智能透视

- planner v2：实际用时反哺时间预估（estimate/actual 闭环生效，报告 §3.2 痛点 5）、个人节奏建模（时段×精力曲线自学习）、重排自动建议（日历变化触发）。
- 智能透视编辑器：过滤器 AST 的可视化编辑 + 保存（S10 打底的技术还债点）。

### M16（S31–S32）：Web 端 + 本地化

- Web 端（只读 + 轻编辑兜底，报告 §6.2）：复用 Flutter Web + 领域/数据包；同步只读优化（增量 pull + 本地 IndexedDB 缓存）；明确 Web 端性能红线（首屏 <3s）。
- 本地化 zh/en/ja 完成（i18n 自 Phase 1 S11 抽取，本阶段补日语 + 全量走查）；本地化隐私政策与条款三语版。

## Part C · 跨阶段工程注意事项

1. **协议前向兼容**：MCP 工具集与公开 API 复用 `protocol` 包 schema，任何破坏性变更走 major 版本并保留旧版 ≥6 个月。
2. **AI 成本复检点**：M13（MCP 引入外部代理调用量不可控，需按 API key 二次限流）、M15（planner v2 学习模型上云前先本地试验）。
3. **隐私边界扩展评审**：M13 前更新隐私政策（第三方代理可见范围、审计日志留存期）；邮件转发地址属 L1。
4. **多端测试矩阵**：S24 起混沌套件覆盖四端并发；1.0 前四端 × 亮暗 × 三语 golden UI 全量刷新。
5. **公开路线图运营**：Phase 2 起维护 `docs/public-roadmap.md`（用户可见，build-in-public），与内部计划分离，防止竞争情报泄露。
